# REQUIREMENTS — Correção do crash em /dashboard/providers/[id]

**Contexto:** a página de provider do ZRouter quebrava no browser com "This page couldn't load".
Causa raiz já identificada e corrigida por EVE: `DiscoverModelsModal.js` chamava `useCallback()`
sem importá-lo de `react` (ReferenceError em runtime — invisível para o bundler).

**Bug já corrigido:** `src/app/(dashboard)/dashboard/providers/[id]/DiscoverModelsModal.js`

**Teste de regressão já criado:** `tests/unit/react-hook-imports.test.js` — percorre `src/`,
detecta qualquer hook do React usado sem import. Validado: falha quando o bug é reintroduzido.
