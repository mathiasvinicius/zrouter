## PARTE A — Backend: endpoint para listar cadernos

### A1. Novo endpoint `GET /api/sources/open-notebook/notebooks`
Cria `src/app/api/sources/open-notebook/notebooks/route.js`:

- Consulta a API do Open Notebook (`OPEN_NOTEBOOK_URL`) com autenticação
  (`OPEN_NOTEBOOK_PASSWORD`), no endpoint `/api/notebooks`
- Retorna uma lista **normalizada e mínima** — não repasse a resposta crua:
  ```json
  { "notebooks": [ { "id": "notebook:xxx", "name": "ArianeMathias", "description": "..." } ],
    "count": 4 }
  ```
- **Nunca** devolva credencial nem URL interna na resposta
- **Fail-open:** se o Open Notebook estiver fora, retorne `{notebooks: [], error: "unavailable"}`
  com HTTP 200 — a UI mostra "não foi possível carregar", não quebra o modal
- Guarde a chamada com um **cache curto** (ex.: 60s em memória) para não bater no serviço a cada
  abertura de modal

### A2. Reaproveitar o cliente existente
Já existe um cliente para o Open Notebook em `open-sse/sources/openNotebookBackend.js` — **leia o
arquivo** e reuse o mesmo padrão de autenticação/base URL. Não invente um segundo caminho.

### B2. Comportamento do escopo `notebooks` — **DECISÃO JÁ TOMADA (não reabra)**

**Verificado por execução real** em `openNotebookBackend.js:47`:

```js
const allowed = new Set((entry.notebooks || []).map(String));
if (allowed.size === 0) return [];     // lista vazia = NENHUM resultado
```

E provado ao vivo:
```
notebooks=[]          → 0 resultados
notebooks=[<id real>] → 3 resultados
notebooks=["*"]       → 0 resultados   (wildcard não existe hoje)
```

Ou seja: **lista vazia significa "nenhum", não "todos".** Isso é uma armadilha — quando as
fontes foram ligadas nas chaves, `notebooks: []` foi gravado e a chave ficou **cega** para o
Open Notebook sem ninguém perceber.

**Portanto, implemente um marcador explícito de "todos":** use `"*"` e ajuste o backend para
tratá-lo como "sem restrição":

```js
const allowed = new Set((entry.notebooks || []).map(String));
const allowAll = allowed.has("*");
if (allowed.size === 0) return [];          // continua: nada autorizado = nada retorna
// ... e no filtro:
if (!allowAll && !notebooks.some((nb) => allowed.has(String(nb)))) return null;
```

Mantenha o comportamento atual de `[]` (nada) para não alterar o significado de keys existentes.
O `"*"` é **aditivo** e explícito.

Aplique o mesmo raciocínio ao `getOpenNotebookSource` (segunda função do arquivo), que tem o
mesmo filtro.
